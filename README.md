# mention-ice.github.io

Home page of the mention ICE (Information & Communication Engineering), third year at CentraleSupélec. It is served at https://mention-ice.github.io/ by GitHub Pages, from the `main` branch of this repository.

- `index.html`: the whole page, in one self-contained file (styles, scripts, logos and illustrations are inline; the only outside resource is Google Fonts).

The other pages of the site live in their own repositories and keep their own addresses:

- https://mention-ice.github.io/Bit2Noisy/ and https://mention-ice.github.io/Bit2Noisy/chat/ (`mention-ice/Bit2Noisy`)
- https://mention-ice.github.io/projets/ (`mention-ice/projets`)

The course hours on the page come from the 2025-2026 course sheets of the CentraleSupélec catalogue.
